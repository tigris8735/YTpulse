# Бизнес-требования

## 1. Обзор проекта

**YT Pulse** — веб-сервис (SaaS-прототип) для авторов YouTube, ориентированный на анализ американских трендов, локальный разбор кликабельности превью и генерацию контента (превью и роликов) на тарифе Pro.

## 2. Цели проекта

### 2.1. Бизнес-цели
- Создать быстрый инструмент для мониторинга трендов YouTube в регионе US без сложных настроек
- Автоматизировать анализ визуальных паттернов успешных превью через локальные алгоритмы
- Предоставить авторам генеративный пайплайн для создания превью и видео-контента
- Протестировать платную модель (Free / Pro) через интеграцию с тестовой ЮKassa

### 2.2. Пользовательские цели
- Видеть актуальные тренды США с фильтрами (Shorts, Longform, Gaming, AI, Finance)
- Понимать, почему конкретное превью выглядит кликабельным, на основе локального разбора
- Генерировать пак из 3 вариантов превью по выбранному тренду (только Pro)
- Создавать задачи на генерацию ролика и отслеживать их статус (только Pro)

## 3. Решаемые проблемы

### 3.1. Основные проблемы
- **Неизвестность трендов** — автор не знает, что сейчас популярно в американском сегменте YouTube
- **Субъективность оценки превью** — сложно объективно понять, почему чужое превью "цепляет"
- **Высокая стоимость production** — создание превью и роликов требует дизайнеров и монтажёров
- **Риск платных экспериментов** — непонятно, окупится ли инвестиция в инструмент

### 3.2. Решение YT Pulse
- 🇺🇸 **Лента трендов US** — подгружается из YouTube Data API `mostPopular` (регион US), 6 фильтров
- 🔍 **Локальный разбор превью** — MediaPipe + OpenCV определяют 4 признака кликабельности (лицо, контраст, текст, центр объекта)
- 🎨 **Генерация пака превью** — текст (Groq/Gemini) + изображение (Pollinations/Gemini Flash Image), 3 варианта 16:9
- 🎬 **Очередь ролика** — создание задачи на генерацию видео со статусами `queued → rendering → ready`

## 4. Целевая аудитория

| Группа | Описание | Основные потребности |
|--------|----------|---------------------|
| **Начинающие авторы** | Блогеры с 1K–50K подписчиков | Понять тренды и научиться делать кликабельные превью |
| **Контент-менеджеры** | SMM-специалисты и редакторы | Быстро сгенерировать варианты превью для роликов |
| **Русскоязычные авторы** | YouTubers, ориентированные на US-аудиторию | Мониторить американские тренды для адаптации контента |

## 5. Основные возможности

### 5.1. High-Level Features

1. **📈 Лента трендов США**
   - Загрузка популярных роликов региона US через `mostPopular`
   - Шесть фильтров: All, Shorts, Longform, Gaming, AI, Finance
   - Кэширование в Neon PostgreSQL, обновление по кнопке

2. **🔍 Разбор превью (Why it clicks)**
   - Локальный анализ JPG-обложек через MediaPipe и OpenCV
   - Три видимых тега: Face closeup, High contrast, Text area
   - Сортировка роликов по сумме баллов (`score_sum` 0–4)

3. **🎨 Генерация пака превью (Pro)**
   - Форма на основе выбранного тренда
   - Текстовые варианты через Groq/Gemini
   - Изображения через Pollinations или Gemini Flash Image
   - Ретраи и запасной провайдер обязательны

4. **🎬 Очередь ролика (Pro)**
   - Создание задачи `generation_jobs` типа `video`
   - Статусы: `queued → rendering → ready`
   - В прототипе — локальная заглушка MP4 (опционально FFmpeg-склейка клипов)

5. **💳 Тарифы и оплата**
   - Free: лента, фильтры, разбор превью
   - Pro (1 мес / 6 мес / год): генерация превью + очередь ролика
   - Тестовая ЮKassa (без реальных списаний)

## 6. Критерии успеха

### 6.1. Количественные метрики
- Лента трендов обновляется за <5 секунд при нажатии "Обновить кэш"
- Разбор превью (MediaPipe + OpenCV) выполняется в фоне при обновлении кэша
- 3 варианта превью генерируются за <30 секунд
- Тестовая оплата успешно ставит `plan = pro` в 100% случаев

### 6.2. Качественные метрики
- UI соответствует макетам ТЗ (тёмная тема, сайдбар 228 px, рельс 320 px, нижний бар 72 px)
- Free-пользователь чётко понимает границу тарифа через экран "Возможности" и замки
- Отсутствие "галлюцинаций" в разборе превью — только локальные, проверяемые признаки
