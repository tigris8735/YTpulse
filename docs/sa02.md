# Системный анализ

## 1. Функциональные требования

### 1.1. Управление пользователями и сессиями
- **Веб-доступ** к кабинету с любых устройств через браузер
- **Регистрация и вход** по почте и паролю, сессия на Vercel
- **Новый пользователь** сразу получает план Free

### 1.2. Лента трендов США
- **📤 Загрузка трендов**
  - Источник: YouTube Data API v3, эндпоинт `mostPopular`, регион `US`
  - Запрет на использование `search.list`
  - Автоматическая нарезка по 6 фильтрам на сервере

- **📊 Управление кэшем**
  - Хранение в таблице `trends_cache` (Neon PostgreSQL)
  - Поля: `filter`, `region`, `youtube_json`, `fetched_at`
  - Обновление по кнопке "Обновить кэш" или при открытии ленты, если кэш протух

### 1.3. Разбор превью (Why it clicks)
- **💻 Локальный анализ**
  - Скачивание JPG с `i.ytimg.com` (приоритет: `hqdefault` → `maxresdefault` → `mqdefault`)
  - MediaPipe Face Detection: определение площади лица (порог ≥ 12% кадра)
  - OpenCV: контраст (σ яркости ≥ 55), текстовая зона (площадь ≥ 8%), центр объекта
  - Сохранение в `preview_tags`: 4 булевых поля + `score_sum` (0–4)

- **🎯 Сортировка**
  - `score_sum` по убыванию, при равенстве — исходный порядок `mostPopular`
  - Просмотры YouTube в формулу не входят

### 1.4. Генерация (только Pro)
- **Превью**
  - Текст через Groq или Gemini
  - Картинка через Pollinations или Gemini Flash Image
  - Ретраи и запасной провайдер обязательны
  - 3 варианта 16:9, визуальный уровень соответствует референсу

- **Ролик**
  - Задача в `generation_jobs` с типом `video`
  - Статусы: `queued → rendering → ready`
  - В прототипе — локальная заглушка MP4 (или контур §8.1: клипы + FFmpeg)

### 1.5. Оплата
- **ЮKassa Test** — настоящий виджет, деньги не списываются
- **Тарифы**: Pro на 1 мес (700 ₽), 6 мес (1800 ₽), 1 год (7000 ₽)
- **Webhook** пишет сырой payload в таблицу `payments`
- **Экраны**: тарифы → оплата → успех / ошибка

## 2. Нефункциональные требования

### 2.1. Производительность
- **Время отклика UI**: <1 секунды для переключения вкладок
- **Обновление кэша**: <10 секунд для полного пересчёта ленты + разбора новых превью
- **Генерация превью**: первый вариант <15 секунд, полный пак <30 секунд
- **AI-генерация текста**: первый токен <3 секунд

### 2.2. Архитектурные особенности
- **Serverless**: Next.js на Vercel Hobby, API-роуты как serverless functions
- **Кастомный разбор превью**: отказ от внешних API кликабельности в пользу MediaPipe + OpenCV
- **Кэширование**: повторный разбор превью не выполняется, пока жив кэш трендов
- **Прототипные ограничения**: нет автопродления, нет боевых списаний, нет внешнего cron

### 2.3. Надёжность
- **Доступность**: 95% uptime при работающем Vercel и Neon
- **Обработка ошибок**: информативные сообщения при недоступности YouTube API или AI-провайдеров
- **Fallback**: если AI-провайдер изображений недоступен — запасной; если видео недоступно — заглушка

## 3. Технологический стек

### 3.1. Frontend
- **Фреймворк**: Next.js (React)
- **Стилизация**: TailwindCSS (тёмная тема, кастомная палитра)
- **Запросы**: Fetch API

### 3.2. Backend
- **Язык**: TypeScript / JavaScript (Node.js)
- **Фреймворк**: Next.js API Routes (serverless functions на Vercel)
- **Парсинг / анализ**: OpenCV (opencv-python), MediaPipe Face Detection
- **Склейка видео**: FFmpeg (опционально, для контура §8.1)

### 3.3. База данных
- **Основная**: Neon.tech PostgreSQL (free tier)
- **ORM**: Prisma или аналогичный

### 3.4. Внешние API
- **YouTube Data API v3**: `mostPopular` (регион US)
- **AI Текст**: Groq API, Google Gemini API
- **AI Изображения**: Pollinations API, Gemini Flash Image
- **AI Видео** (опционально): Luma Ray API, fal.ai / PiAPI (Kling), DashScope Wan
- **Платежи**: ЮKassa Test

## 4. Ограничения системы

### 4.1. Технические ограничения
- Vercel Hobby ограничивает время выполнения serverless functions — нельзя разбирать пачку JPG в запросе UI
- Разбор превью выполняется только при обновлении кэша, не на каждый клик
- Free tier Neon имеет ограничения по соединениям и размеру

### 4.2. Функциональные ограничения
- Нет `search.list` — поиск роликов строкой невозможен
- Нет чужого CTR, процентов кликабельности, emotion, curiosity gap
- Четвёртый тег (`center_object`) считается, но не показывается на экране
- Генерация видео в прототипе — заглушка (или FFmpeg-склейка по §8.1)
- Только тестовые платежи, автопродления нет
