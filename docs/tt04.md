## 3. Технические детали реализации

### 3.1. Ключевые архитектурные решения

#### **Локальный разбор превью без внешних API**
```typescript
// Serverless function на Vercel — запускается только при обновлении кэша
async function analyzePreview(jpgBuffer: Buffer): Promise<PreviewTags> {
  const face = await mediapipeFaceDetection(jpgBuffer); // площадь ≥ 12%
  const contrast = await opencvContrast(jpgBuffer);       // σ ≥ 55
  const textArea = await opencvTextArea(jpgBuffer);       // площадь ≥ 8%
  const centerObj = await opencvCenterObject(jpgBuffer);  // центр < 30% диагонали

  const score_sum = (face ? 1 : 0) + (contrast ? 1 : 0) + 
                    (textArea ? 1 : 0) + (centerObj ? 1 : 0);

  return { video_id, face_closeup: face, high_contrast: contrast, 
           text_area: textArea, center_object: centerObj, score_sum };
}
```

#### **Проверка плана Pro**
```typescript
// Middleware / Server Action
function checkProAccess(user: User): boolean {
  return user.plan === 'pro' && new Date() < user.pro_expires_at;
}
// На Free: экран "Генерация" и "Очередь" показывают замок + CTA к тарифам
```

### 3.2. Оптимизация под Vercel Hobby
- Разбор превью (MediaPipe + OpenCV) выполняется в фоновом job при обновлении кэша, а не в UI-запросе
- Повторный разбор не выполняется, если `preview_tags` уже содержит `video_id` и кэш не протух
- AI-запросы (Groq, Pollinations) с ретраями и fallback-провайдером
- Все API-ключи только в переменных окружения Vercel
